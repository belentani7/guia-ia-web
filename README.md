# guia-ia-web

Web interactiva en español para empezar con IA: modelos, APIs, costes, datos y ruta de 90 días.

## Stack

- Primary language: TypeScript
- Node project (`package.json` present)

## Getting started

```bash
git clone https://github.com/belentani7/guia-ia-web.git
```

```bash
npm install
npm run dev
```
